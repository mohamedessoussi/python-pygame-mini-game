# 🎮 2D Shooting Game

A 2D shooting game developed using Python and Pygame.

## About The Project

An interactive 2D action game where players control a hero, move through the environment, jump, and shoot enemies.

## Features

- Player movement and jumping.
- Enemy animations and interactions.
- Shooting mechanics.
- Collision detection.
- Score system.
- Main menu.
- Restart functionality.
- Win and game-over states.
- Sound effects.

## Technologies

- Python 3
- Pygame

## Installation

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Open the game directory:

   ```bash
   cd tOW
   ```

4. Run the game:

   ```bash
   python main.py
   ```

## Controls

| Key | Action |
|---|---|
| Left Arrow / A | Move left |
| Right Arrow / D | Move right |
| Up Arrow | Jump |
| S | Shoot in facing direction |
| F | Shoot forward |
