# 🎮 Python Pygame Mini Game

## 📌 About
A 2D mini game developed using Python and Pygame.

## 🛠️ Technologies
- Python
- Pygame

## ⚙️ Installation

1. Clone the repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Run the game:
   ```bash
   python main.py
   ```
