# 🎮 2D Shooting Game

A 2D shooting game developed using Python and Pygame.

## 📌 About The Project

This project is a 2D action game where the player controls a character, moves through the game environment, jumps, and shoots enemies to increase the score.

## ✨ Features

- Player movement and jumping.
- Enemy system.
- Shooting mechanics.
- Collision detection.
- Score tracking.
- Main menu.
- Restart functionality.
- Win and game-over states.

## 🎮 Controls

| Key | Action |
|---|---|
| ← / A | Move left |
| → / D | Move right |
| ↑ | Jump |
| S | Shoot in facing direction |
| F | Shoot forward |

## 🛠️ Technologies

- Python 3
- Pygame

## ⚙️ Installation

1. Clone the repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Install dependencies:
   ```bash
   pip install pygame
   ```

3. Run the game:
   ```bash
   python main.py
   ```
